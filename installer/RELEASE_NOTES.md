## SlideVideoDivider 0.1.0

音声付きスライド動画から、スライド画像と文字起こしのPDFを作成するWindowsアプリです。

### 主な機能

- スライド切替を自動検出し、**区間ごとに音声を分割して文字起こし**（スライドとの対応ズレなし）
- **GPU自動判定**：Vulkan対応GPUがあれば検出して並列文字起こし、CPUのみの環境では自動的にCPUで実行
- PDF出力：スライド＋文字起こし / スライドのみ / 文字起こしのみ
- スライドノート編集（Undo / Redo、`Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`）
- FFmpeg / FFprobe を同梱し、追加インストール不要
- 起動時の自動更新チェック（ワンクリックで更新）
- 処理はすべてローカルで実行。音声・動画は外部へ送信されません

### インストール

`SlideVideoDivider-0.1.0-setup.exe` を実行してください。管理者権限は不要です（ユーザー単位インストール）。

### 注意

- 音声認識モデルは初回の変換時に自動でダウンロードされます（既定: large-v3-turbo q8）
- GPU版はVulkanバックエンドを使用します。NVIDIA/AMD/Intelの主要GPUで動作します
